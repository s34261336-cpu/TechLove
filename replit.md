# TechLove

Импортированный Python-бот с AI-ассистентом в Telegram, выбором моделей и ролей, историей диалогов и административными инструментами.

## Запуск

- Рабочий процесс **TechLove Bot** запускает `bash scripts/start-bot.sh`, затем `uv run --locked python app.py`.
- Пользователи выбирают модели по семействам (GPT, Claude, Gemini и другим), не по API-провайдерам.
- Для запуска нужен `BOT_TOKEN`; каталог AnyModel использует `ANYMODEL_API_KEY`. Другие маршруты включаются своими секретами.
- Данные пользователей и моделей хранятся в JSON-файлах. Раздел кейсов отключён; существующие файлы кейсов оставлены без изменений.

## Стек

- Python 3.12
- aiogram 3
- OpenAI-совместимые AI API и каталог моделей AnyModel
- aiohttp
- JSON-файлы для хранения состояния

## Возможности

- Каталог AI-моделей, сгруппированный по семействам, и роли ассистента
- Распознавание голосовых сообщений локальной моделью Whisper
- История диалогов и настройки температуры
- Генерация и анализ изображений
- Профиль пользователя и система ZenoToken
- Антиспам-защита
- Административная панель с управлением пользователями, моделями и рассылками
